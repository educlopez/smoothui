## Features

- Sizes: `sm`, `md`, `lg`
- `role="status"` with default `aria-label="Loading"`
- Honors `prefers-reduced-motion`
- SmoothUI-owned

## States

### Features

Three sizes side by side.

### Labeled

Spinner next to visible status copy.

## Accessibility

### ARIA Attributes

| Attribute | Element | Purpose |
|-----------|---------|---------|
| `role="status"` | Root | Live loading status |
| `aria-label` | Root | Accessible name when no visible text |

### Reduced Motion

Rotation stops when reduced motion is preferred.
