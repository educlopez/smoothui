## Features

Style variants, colour families, a size scale, a candy brand treatment, and a quiet press scale. Polymorphic via `asChild` (Radix Slot). Focus-visible ring and a disabled state with reduced opacity.

## Variants

Solid, soft, outline, ghost, link, and candy, each available in the neutral, accent, blue, amber, green, and destructive colour families. The legacy `default`, `secondary`, and `destructive` variants still work for existing call sites.

## Sizes

`xs`, `sm`, `default`, `lg`, plus `icon-sm`, `icon`, and `icon-lg` for icon-only buttons, which keep the hit target square.

## Usage

Loading, disabled, leading/trailing icons, and pill shape — the everyday compositions.

```tsx
import SmoothButton from "@/components/smooth-button";

export default function Example() {
  return <SmoothButton variant="candy">Get Started</SmoothButton>;
}
```
