## Features

- `Command` root with input, list, groups, items, shortcuts
- `CommandDialog` wraps the palette in SmoothUI Dialog
- Compose with `Kbd` for shortcut hints
- Delphi Command / Astryx Command Palette as visual refs

## States

### Features

Inline command list with shortcuts.

### Dialog

Modal palette toggled by button / ⌘J.

## Accessibility

cmdk handles listbox keyboard navigation. Dialog provides focus trap when modal.
