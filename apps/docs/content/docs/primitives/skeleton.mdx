## Features

- Shape via className (`h-*`, `w-*`, `rounded-*`)
- Optional shimmer animation (on by default)
- `aria-hidden` — parent should expose busy state
- SmoothUI-owned

## States

### Features

Avatar + text row and card block placeholders.

### Static

Shimmer disabled for a solid pulse-free fill.

## Accessibility

### Reduced Motion

Shimmer disables when `prefers-reduced-motion` is set.
