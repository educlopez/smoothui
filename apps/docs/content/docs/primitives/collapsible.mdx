## Features

`CollapsibleRoot`, `CollapsibleTrigger`, and `CollapsiblePanel` wrap Base UI Collapsible. Panel height uses `--collapsible-panel-height` with opacity; the chevron rotates when the panel is open.

## States

### Features

Closed by default — click the trigger to reveal content.

### Default open

Starts expanded via `defaultOpen`.

## Accessibility

### Keyboard Interactions

| Key | Description |
|-----|-------------|
| `Enter` / `Space` | Toggles the panel |
| `Tab` | Moves focus to / from the trigger |

### Reduced Motion

Height and opacity transitions are skipped when `prefers-reduced-motion` is preferred.
