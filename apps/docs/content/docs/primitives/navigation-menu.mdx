## Features

- Trigger + content panels with a shared viewport
- Compound parts: `NavigationMenuRoot`, `NavigationMenuList`, `NavigationMenuItem`, `NavigationMenuTrigger`, `NavigationMenuContent`, `NavigationMenuLink`, `NavigationMenuViewport`
- Smooth panel size transitions
- Base UI by default; Radix twin available via style

## States

### Features

A product header with Product / Resources panels and a Pricing link.

## Accessibility

Triggers are buttons; links are keyboard reachable. Prefer short panel content.
