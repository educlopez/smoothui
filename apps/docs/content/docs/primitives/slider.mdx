## Features

Compound `SliderRoot` / `Control` / `Track` / `Indicator` / `Thumb`, plus a thin default convenience for a single numeric value (`value` / `defaultValue`, `min`, `max`, `step`, `onValueChange`, `disabled`). Thumb scales on press (`whileTap`) and keeps a focus ring.

## States

### Features

Controlled single-value slider with live readout.

### Disabled

Non-interactive track and thumb.

## Accessibility

### Keyboard Interactions

| Key | Description |
|-----|-------------|
| `Arrow` keys | Adjust value by `step` |
| `Home` / `End` | Jump to min / max |
| `PageUp` / `PageDown` | Larger steps |

### Reduced Motion

Thumb press scale is disabled when reduced motion is preferred.
