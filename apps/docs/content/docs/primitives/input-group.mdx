## Features

- `InputGroupAddon` for start / end slots
- `InputGroupText` for static affixes
- Focus and invalid rings lift to the group shell
- Compose with SmoothUI `Input`

## States

### Features

Currency prefix and domain prefix/suffix.

## Accessibility

Label the nested Input (`aria-label` or Field). Affix text is decorative.
