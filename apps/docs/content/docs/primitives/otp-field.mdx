## Features

- Configurable `length` (default 6)
- Paste fills consecutive slots
- Optional `mask` for shared screens
- Compound parts: `OTPFieldRoot`, `OTPFieldInput`
- Base UI by default; Radix twin is a hand-rolled multi-input (Radix has no OTP Field)

## States

### Features

A six-digit verification code.

### Masked

Characters are obscured.

## Accessibility

Provide a visible `label` or an `aria-label`. Each subsequent slot announces its position.
