## Features

- Horizontal menu bar with File / Edit style menus
- Compound parts: `MenubarRoot`, `MenubarMenu`, `MenubarTrigger`, `MenubarContent`, `MenubarItem`, `MenubarSeparator`
- Arrow-key roving focus across triggers; open menus with Enter / Space
- Base UI by default; Radix twin available via style

## States

### Features

A classic File / Edit / View menubar.

## Accessibility

### Keyboard

Arrow Left / Right move between menus. Arrow Down opens the focused menu.
