## Features

Base UI Field compound for labeling and validating form controls. Vertical stack with label, description, styled control, and error messaging.

## Usage

Compose `Field`, `FieldLabel`, `FieldControl`, `FieldDescription`, and `FieldError`. The root wires ids and `aria-*` associations automatically.

## Accessibility

### ARIA Attributes

| Attribute | Element | Purpose |
|-----------|---------|---------|
| `for` / `id` | Label ↔ Control | Associates the label with the control |
| `aria-describedby` | Control | Links description and error messages |
| `aria-invalid` | Control | Marks the control when the field is invalid |
