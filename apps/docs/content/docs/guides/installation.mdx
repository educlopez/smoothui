## Installation (SmoothUI CLI)

<BodyText>
The SmoothUI CLI provides an interactive way to browse and install components with automatic dependency resolution.
</BodyText>

<FeatureCard title="Base UI by default" variant="info">
Owned SmoothUI primitives (button, dialog, checkbox, …) ship on **Base UI** by
default (`/r/{name}.json` and `base-*` styles). Radix projects set a non-`base-*`
style and point at `https://smoothui.dev/r/{style}/{name}.json`. See
[Primitives](/docs/primitives).
</FeatureCard>

### Add Components

<PackageManagerTabs
  pnpm="pnpm dlx smoothui-cli@latest add siri-orb"
  npm="npx smoothui-cli@latest add siri-orb"
  yarn="yarn dlx smoothui-cli@latest add siri-orb"
  bun="bunx smoothui-cli@latest add siri-orb"
/>

## Installation (shadcn Registry)

<BodyText>
SmoothUI is an official shadcn registry. Use the `@smoothui{:js}` namespace.
Owned primitives ship on **Base UI** by default; Radix projects should use the
style-aware registry URL.
</BodyText>

```json
{
  "style": "base-nova",
  "registries": {
    "@smoothui": "https://smoothui.dev/r/{style}/{name}.json"
  }
}
```

<FeatureCard title="Base by default" variant="info">
Plain `@smoothui/...` installs get the Base twin. Set a non-`base-*` style plus
the style-aware URL above for Radix — see [Primitives](/docs/primitives).
</FeatureCard>

### Install Components

<BodyText>
Install SmoothUI components using the shadcn CLI with the `@smoothui{:js}` namespace:
</BodyText>

<PackageManagerTabs
  pnpm="pnpm dlx shadcn@latest add @smoothui/siri-orb"
  npm="npx shadcn@latest add @smoothui/siri-orb"
  yarn="yarn dlx shadcn@latest add @smoothui/siri-orb"
  bun="bunx shadcn@latest add @smoothui/siri-orb"
/>

### Install Multiple Components

<PackageManagerTabs
  pnpm="pnpm dlx shadcn@latest add @smoothui/rich-popover @smoothui/float-input"
  npm="npx shadcn@latest add @smoothui/rich-popover @smoothui/float-input"
  yarn="yarn dlx shadcn@latest add @smoothui/rich-popover @smoothui/float-input"

### Use Components

<BodyText>
Import and use the installed components in your React application:
</BodyText>

```tsx
import { SiriOrb } from "@/components/smoothui/ui/SiriOrb"
import { RichPopover } from "@/components/smoothui/ui/RichPopover"

export default function App() {
  return (
    <div>
      <SiriOrb size="200px" />
      <RichPopover />
    </div>
  )
}
```
